## Как начать персональный чат

Приложи PDF статьи, этот README и только своё персональное задание. Вставь раздел «Стартовый промпт для Claude или ChatGPT» из задания. Формулы и таблицы заново в сообщение копировать не требуется. На первом шаге модель сверяет нужный фрагмент с PDF и выдаёт конкретный результат по роли. Архивы, проверяемый SHA и вывод реальных команд добавляй по мере их появления. Для работы с результатами укажи SHA принятого кода и run_id. Если чат не может прочитать часть вложения, приложи соответствующую страницу PDF или выведи её номер и нужную формулу вручную.
